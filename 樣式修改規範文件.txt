# 电线电缆跨平台 App 专用全局视觉与 UI 规范 (V1.2)
适用端：iOS / Android / 鸿蒙 (HarmonyOS) | 核心目标：严谨专业、防错提效、多端统一

## 一、 色彩体系与电缆行业“防撞色”专有规范
1. 品牌与主色调（Primary）：工业科技蓝 `#0A66C2`（用于全局主按钮、激活状态、核心可点击 Tab）。防撞色警戒：严禁将蓝色用于“库存不足”或“超出规格”等负面警示。
2. 电缆工程业务状态色：
   - 导体正常态：沉稳深灰 `#2C3E50`（表格主参数、规格型号文字）
   - 库存充足/状态正常：工业绿 `#10B981`
   - 库存预警/价格波动风险：电缆黄 `#F59E0B`
   - 高危/库存为零/异常截断：警示红 `#EF4444`
3. 背景与卡片底色：全局页面底色统一使用沉浸式工业浅灰 `#F3F4F6`；数据卡片底色纯白 `#FFFFFF`。

## 二、 电缆业务核心字段专用色彩标识规范（报价单与明细表专项）
- 常规基础信息（商品名称、通用描述等）：沉稳深灰 `#2C3E50`
- 核心技术参数（电压等级、产品型号、产品规格、质量标准）：工业科技蓝 `#0A66C2`
- 商务价格高亮（订购数量、执行单价、税率标识、小计金额）：警示红 `#EF4444`（核心风险防护，一眼识别）

## 三、 尺寸、间距与移动端多端自适应规范
1. 相对单位原则：统一采用响应式单位（`rpx` 或 `vw/vh`），严禁写死绝对像素（px）。
2. 圆角与留白：基础间距以 `8px` 为倍数（`8rpx/16rpx/24rpx/32rpx`）；卡片容器统一 `16rpx`，内部小按钮/标签 `8rpx`。
3. 触控区域保障：所有可点击按钮最小高度不得低于 `88rpx`。

## 四、 电缆行业特有 UI 与防冲突设计
1. 数字与参数排版：核心计算字段必须使用等宽数字或对齐排版，防止小数点错位导致报价失误。
2. 长文本截断保护：电缆型号等长字符串必须做单行 `ellipsis` 截断加长按气泡查看，或折行展示。
3. 底部安全区：底部固定操作栏必须适配各类手机底部黑条安全区。

## 五、 文本、标题与数据表格的严格对齐规范
1. 表单标签：左侧文字标签统一宽度或统一基准对齐；输入框与下拉选择框高度和留白一致。
2. 数据表格：文字类内容统一左对齐；数值类参数（千米重量、价格、数量）必须右对齐或等宽对齐。
3. 标题层级：模块大标题左侧带统一视觉指示条或与内容卡片左边界严丝合缝左对齐。
4. 内容换行：长文本必须开启自动换行与多行自适应，高度由内容自动撑开。

## 六、 现场与车间交互防错及体验优化规范
1. 数值输入防误触：库房录入数据必须强制唤起数字键盘（带小数点）；核心字段必须做边界校验（禁止输入负数、限制小数位数）。
2. 核心操作防呆：生成报价单、修改铜价、清空缓存等高危操作必须加入弹窗二次确认（Dialog）或长按触发机制。
3. 弱网提示：网络断开或超时，顶部必须有明显的离线横幅提示（Banner），并允许查看已缓存数据。
4. 骨架屏加载：查询庞大规格库或实时铜价时，严禁全屏白屏或转圈，必须采用骨架屏（Skeleton Screen）。

【执行要求】：本规范为硬性设计与开发标准，所有涉及 UI 渲染与外包交付的代码，必须严格对照执行，未达标者一律打回重做。
